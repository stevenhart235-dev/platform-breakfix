# Future architecture decisions

These decisions were identified during discovery but are intentionally deferred
until their requirements are concrete:

- AKS networking, pod addressing, and outbound connectivity
- Kubernetes API exposure and authorized network ranges
- Entra authorization, Azure RBAC, and Kubernetes RBAC boundaries
- Portable storage semantics and Azure storage-class selection
- Optional ingress implementation
- Minimum observability and logging profile
- Registry ownership and long-term preservation
- Supported operator shells and shared command interface
- Lab TTL, cost reporting, and automatic stale-resource cleanup
- Scenario packaging, inspection evidence, and reset semantics
